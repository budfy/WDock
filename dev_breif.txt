📌 НАЗВА ПРОЕКТУ: WDock
- Скруглені кути
- Адаптивні іконки (48x48 px за замовчуванням)
- Темна/світла тема (синхронізація з темою Windows)
- Плавні анімації: поява, ховання, розгортання груп

──────────────────────────────────────────────────────
✅ ОСНОВНІ ФУНКЦІЇ ТА ВИМОГИ
──────────────────────────────────────────────────────

1. ДОДАВАННЯ ТА ВИДАЛЕННЯ ЯРЛИКІВ
- Можливість перетягувати ярлики (.lnk, .exe) на док-панель.
- Візуальний фідбек під час перетягування (підсвічування області приймання).
- Видалення: перетягування за межі доку (із зоною видалення) або через контекстне меню.
- Збереження списку ярликів у конфігураційному файлі (config.json).

2. ГРУПУВАННЯ ЯРЛИКІВ
- Перетягування одного ярлика на інший створює групу.
- Група відображається як один елемент (із індикатором кількості).
- При натисканні — розкривається спливаюче меню з усіма ярликами групи.

3. ПОЗИЦІОНУВАННЯ ДОК-ПАНЕЛІ
- Підтримка прикріплення до:
   • Низу (за замовчуванням)
   • Верху
   • Ліворуч
   • Праворуч
- Автоматичне оновлення позиції при зміні.

4. ВИРІВНЮВАННЯ ЯРЛИКІВ
- Для горизонтальних панелей (верх/низ): ліворуч, по центру, праворуч.
- Для вертикальних панелей (ліворуч/праворуч): вгору, по центру, вниз.
- Налаштування через контекстне меню.

5. КОНТЕКСТНЕ МЕНЮ ДОК-ПАНЕЛІ (права кнопка на вільному місці)
- Прикріпити до → підменю: Верх, Низ, Ліворуч, Праворуч
- Вирівнювання → підменю: Ліворуч/вгору, По центру, Праворуч/вниз
- Налаштування → відкриває вікно налаштувань
- Про програму → вікно з назвою, версією, посиланням
- Завершити WDock → коректне закриття

6. КОНТЕКСТНЕ МЕНЮ ЯРЛИКА (права кнопка на ярлику)
- Відкрити
- Переіменувати (відображуване ім’я)
- Видалити з доку
- Властивості ярлика → викликає стандартне контекстне меню Windows (через COM)
- Меню доку → підменю з пунктами з пункту 5

6.1 КОНТЕКСТНЕ МЕНЮ ГРУПИ (права кнопка на групу)

При правому кліку на групу:

- Розгорнути
- Переіменувати групу
- Задати іконку групи:
   • Вибір із вбудованих emoji (🎮, 📊, 🛠️, 🎵, 🌐, 🎯 тощо)
   • Або завантаження зображення (.png, .ico)
- Розгрупувати (розбиває групу, ярлики залишаються в доку)
- Видалити групу (з підтвердженням; видаляє всі ярлики групи з доку)
- Меню доку → підменю з усіма пунктами з пункту 5

7. ПОВЕДІНКА НА ЕКРАНІ
- Завжди зверху (не заважає фокусу)
- Режими:
   • Завжди показувати
   • Ховати при наведенні
   • Інтелектуальне ховання
- Інтелектуальне ховання:
   • Автоматично ховається при повноекранних додатках (ігри)
   • Визначення через аналіз активного вікна (pygetwindow, win32gui)

8. СУМІСНІСТЬ З ПАНЕЛЛЮ ЗАВДАНЬ
- Якщо док прикріплений до низу — розміщується **над панеллю задач**, але **під робочою областю**.
- Використовувати SystemParametersInfo (через ctypes) для отримання розмірів робочої області.

9. НЕ ВІДОБРАЖАТИ ЗАПУЩЕНІ ЗАДАЧІ
- WDock показує лише додані користувачем ярлики.
- Не відображає запущені процеси (на відміну від панелі задач)

🔹 ОРГАНІЗАІЯ ФАЙЛІВ:
- окремі файли під кожну функцію/клас
- окремі файли стилів під кожну сутність

🔹 БІБЛІОТЕКИ:
- GUI: PyQt6 (рекомендовано через підтримку стилів, прозорості, системних інтеграцій)
- Система: pywin32 (win32api, win32gui), ctypes
- Вікна: pygetwindow (для визначення повноекранного режиму)
- Конфігурація: json, os, shutil
- Drag & Drop: QDrag, QMimeData (PyQt6)
- Автозавантаження: реєстр Windows (HKEY_CURRENT_USER\...\Run)
